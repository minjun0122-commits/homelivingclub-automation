# 매일 릴스 루틴

인자로 주제가 오면 그걸 쓰고, 없으면 1단계에서 후보를 제안해요: $ARGUMENTS

파이썬: `C:/path/to/file` (아래에서 `$py`)

## 0. 현재 상태 파악 (항상 먼저)
1. `reels/휴대폰으로_보낼것/*.mp4` 에서 가장 큰 번호 NN 을 찾아요 → 이번 릴스는 NN+1.
2. 가장 최근 `reels/<주제>/render.py` 의 docstring 에서 **직전 BGM 스타일**을 확인해요.
   다음 차례는 `reels/shampoo/bgm.py` 의 `USE = ["piano", "marimba", "piano2", "marimba2"]` 순서대로. 같은 스타일을 연달아 쓰지 않아요.
3. 최근 render.py 3~4개의 `CHORDS` 를 보고 **겹치지 않는 코드 진행**을 고르세요.
4. 이 파일들이 있으면 읽어요. 앞의 것일수록 최신 판단이에요.
   - `~/.claude/instagram/plan.md`: 주간 계획과 /ig-audit 반영 사항
   - `reels/stats.csv`: 형식별 성과. 맨 끝 행의 note 에 예약 일정이 있어서 다음 게시일도 여기서 알 수 있어요
   - `~/.claude/instagram/voice.md`, `~/.claude/instagram/swipe.md`: 말투와 참고 패턴 (swipe 는 표본이 작아요)
   - `C:/path/to/file`: 10/20 까지의 기록

## 1. 주제 고르기
- 이미 쓴 주제(`reels/` 폴더 이름들, 캡션.txt 의 `=== NN_... ===` 제목)는 피해요.
- plan.md 에 해당 날짜 칸이 있으면 그걸 우선해요. "사용자 확인 필요"라고 적힌 칸은 물어본 뒤에 만들어요.
- 생활 전반(주방·욕실·세탁·침구·가전 관리 등)에서 고르고, **정리·수납으로만 좁히지 않아요**.
- 3개 중 1개쯤은 실제 상품 사실을 쓴 **상품 릴스**로 해요. 사용자의 목적이 판매예요.
- 조회가 잘 나온 쪽은 계산형 문제와 귀여운 그림이었고, 답이 뻔한 문제는 약했어요. 표본이 작으니 stats.csv 로 다시 확인해요.
- 인자가 없으면 후보 3개를 한 줄씩 제안하고 사용자가 고를 때까지 기다려요. 인자가 `ㄱㄱ` 이면 직접 골라요.

## 2. render.py 작성 — `reels/<영문주제>/render.py`
형식에 맞는 가장 최근 파일을 복사해서 `CHORDS`, `CARDS`, `draw_item`, 제목, 끝 문구를 바꿔요.

| 형식 | 기준 파일 |
|---|---|
| 생활 퀴즈 | `reels/bleachquiz/render.py` |
| 상품 퀴즈 (계산형, 끝 화면 사진) | `reels/fridgecalc/render.py` |
| 저장용 정리표 | `reels/nofridgetable/render.py` |
| 상품 사용 순서 (0초부터 상품 표기) | `reels/nofrypan/render.py` |

공통 틀:
- 7.5초, 장면 전환 없이 한 장면 연속 애니메이션 (`SCENES = [(TOTAL, s_all)]`).
- 제목은 **y ≥ 290**. 인스타 격자 표지가 y=230 근처를 잘라서, 그 위에 있으면 표지마다 "딱 하나. 몇 번?"만 보여요.
- 중요한 요소는 y < 1500 안에 두되, 끝 화면 문구처럼 일부러 아래에 둔 것은 미리보기로 겹침을 확인해요.
- 퀴즈는 정답 번호를 직전 릴스들과 다르게 하고, `REVEAL` 에서 정답 카드를 마지막에 공개해요.
- `common.py` 의 `canvas, text, appear, ease, render, F` 와 색상 상수를 써요. bgm 은 `reels/shampoo/bgm.py`.
- docstring 에 주제, 정답, 형식 메모, **BGM 스타일**을 적어요 (다음 릴스가 순서를 이어받는 근거).
- 출력 파일명: `homelivingclub_<영문주제>.mp4` 와 `homelivingclub_<영문주제>_ig.mp4`.

상품 릴스:
- 수치와 사용법은 `products/<상품>.yaml` 과 `products/images/<폴더>/detail_*.jpg` (상세페이지 이미지) 에서 직접 확인한 것만 써요. 조리 시간이나 주의사항은 이미지에만 있는 경우가 많아요. 없으면 지어내지 말고 물어봐요.
- 안전 관련 안내(사용 출력 제한, 뜨거움 등)는 캡션에 옮겨요.
- 표기에 쓰는 사진은 YAML 의 `images.main` 이에요. 폴더 이름은 상품 파일 이름과 달라요. 상세 이미지는 공급사가 무단 사용을 금지하니 확인용으로만 보고, 그림은 직접 그려요.
- **11/6 부터 상품명이나 스토어 표기를 0초부터 화면에 넣어요.** 끝 화면에만 두면 평균 시청 5~6초 안에 보이지 않아요.

생활 정보(세제 혼합, 식품 보관, 전기 사용 등)는 사실을 확인하고 써요. 위험할 수 있는 내용이면 캡션에 라벨 안내를 확인하라는 문구를 넣어요.

## 3. 미리보기 → 렌더링
1. `& $py reels/<주제>/render.py --preview` → `_preview.jpg` 를 Read 로 직접 보고 확인해요.
   글자 잘림, 겹침, 깨진 글자(이모지 등)가 없는지 확인하고, 문제가 있으면 고친 뒤 다시 확인해요.
2. `& $py reels/<주제>/render.py` 로 렌더링해요.
3. `_ig.mp4` 를 `reels/휴대폰으로_보낼것/<NN+1>_<한글주제>.mp4` 로 복사해요.

## 4. 캡션 추가 — `reels/휴대폰으로_보낼것/캡션.txt` 맨 끝에 덧붙이기
기존 형식 그대로 (UTF-8 유지). 퀴즈 형식:
```
=== NN_한글주제.mp4 ===
퀴즈 질문, 몇 번? 🤔

1. …
2. …
3. …
4. …

정답은 N번이에요.
이유 1~2줄 (영상 속 숫자와 같게)

몇 번 찍으셨어요? 댓글로 알려주세요 👇
저장해두고 ○○ 하는 날 보기

○○용품은 프로필 링크 '홈리빙클럽'(저희 스토어)에서 볼 수 있어요.

#주제태그 #카테고리태그 #살림팁 #생활퀴즈 #자취템 #홈리빙클럽
```
상품 릴스는 스토어 안내 줄을 이렇게 바꿔요:
`영상 속 ○○(구성)는 저희 스토어 상품이에요. 프로필 링크 '홈리빙클럽'에서 볼 수 있어요.`

할인 문구는 게시일에 할인이 실제로 진행 중일 때만 넣어요.

## 5. 검수와 기록
1. `caption-checker` 에이전트로 새 캡션 블록과 render.py 를 점검해요. "수정 필요"면 고치고, 영상 문구를 고쳤으면 다시 렌더링해서 복사까지 다시 해요.
2. `reels/stats.csv` 끝에 행을 추가해요 (UTF-8, 헤더 유지). 성과 칸은 비워 둬요. /stats 가 나중에 채워요.
   ```
   날짜,NN,제목 (상품이면 "(상품)" 표기),,7.5,,,,,,ans 3; 형식 메모
   ```
   예약이나 게시를 마친 뒤 note 에 `scheduled IG+Shorts 11/6 13:00 (쇼츠ID)` 처럼 일정을 덧붙여요.

## 반드시 지킬 규칙
- 효능·건강 효과를 주장하지 않아요 ("세균 99% 제거", "건강에 좋은" 등 금지).
- 상품이 나오면 "저희 스토어 상품"이라고 밝혀요. 캡션 스토어 안내 문구는 항상 넣어요.
- AI 생성 이미지, 가짜 후기, "제가 하던 것 3가지" 같은 가짜 1인칭 템플릿은 쓰지 않아요.
- 촬영은 권하지 않아요. 사용자가 하지 않기로 했어요.
- **영상 속 글자에는 이모지를 넣지 않아요** (Pretendard 에서 깨져요). 캡션에는 괜찮아요.
- 가격·할인·광고비처럼 돈이 걸린 설정은 이 루틴에서 바꾸지 않아요.
- 로그인·결제·비밀값 입력은 사용자가 직접 해요.
